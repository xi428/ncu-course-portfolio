## 🚀 快速开始

### 1. 克隆仓库（首次使用）
```bash
git clone https://github.com/<你的GitHub用户名>/ncu-course-portfolio.git
cd ncu-course-portfolio
```

### 2. 每周完成作业后三步走
```bash
git add .                                  # 把改动加入暂存区
git commit -m "Week01: 完成 xxx 作业"        # 生成一个版本快照
git push                                   # 推送到 GitHub 远端
```
